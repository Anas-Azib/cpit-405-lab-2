Lab 2: HTML

CPIT-405 Course Site

This lab is about practicing the basic structure of an HTML document and getting familiar with the most commonly used HTML tags.

Throughout this page you will find text formatting, headings, lists, a table, and a simple login form, all built using plain HTML elements.

The strong tag is used to give text strong importance, and it is usually displayed in bold.

The em tag is used to emphasize text, and it is usually displayed in italics.

Water can be written with a subscript as H2O to show the number of atoms.

A mathematical expression such as x2 uses the superscript tag to raise the power.

The span tag is an inline container used to style a specific part of the text.
